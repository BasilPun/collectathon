# Collectathon by B & Arsh

![GIF OF GAME](/gamegif.gif)

Starting off from a template of a collecting game in our SDEV 301 class, this is what we ended up with: A game about a songbird that is tired of getting attacked by bats and thus takes "supplements" to power up and hunt them down 😏.

Goal: Get as much points within the 60 second time limit as possible and in the process, don't forget to roid up so as to get those pesky bats scared of you.

Movement: WASD, Z for boost

Link to game: https://basilpun.github.io/collectathon/
